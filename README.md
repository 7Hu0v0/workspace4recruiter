# Recruiter Workbench

> 给招聘小马喽准备的个人工作台 — 单文件 SPA，浏览器直接打开即用。

## 快速开始

```bash
# 直接浏览器打开
open index.html
```

或者用任意静态文件服务器：
```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 功能模块

| 模块 | 功能 |
|---|---|
| 📁 **规划与复盘** | 周/月/半年时间维度，规划区 + 复盘区分栏，实时自动保存 |
| 📁 **CRM 系统** | 外链 CRM 按钮 + 腾讯文档 iframe 嵌入（支持缩放控制） |
| 📁 **人选运营** | 周/月/半年追踪表格，支持进度筛选、聚合汇总、同步到剪贴板 |

## 技术栈

- **纯前端**：单文件 HTML + CSS + JS，零依赖
- **存储**：localStorage 持久化，无需后端
- **布局**：CSS Grid 深色侧边栏 + 浅色主内容区

## 核心特性

- ✅ 时间区间自动计算（周/月/半年）
- ✅ 时间段动态增删
- ✅ 侧边栏文件夹折叠记忆
- ✅ 人选数据跨周期聚合（月拉周、半年拉月）
- ✅ 进度筛选（未建联 / 已建联 / 已推荐 / 流程中）
- ✅ 腾讯文档 iframe 嵌入 + 缩放滑块
- ✅ 数据一键复制为表格格式（TSV）
- ✅ 状态圆点指示器（空/规划/复盘/全填）

## 自定义

### 修改存储前缀

打开 `index.html`，找到：
```js
var STORAGE_PREFIX = 'recruiter-workbench-';
```
改为你自己的前缀避免键名冲突。

### 修改品牌信息

在 `index.html` 中搜索 `Recruiter Workbench` 和 `RW`，替换为你的品牌名和头像缩写。

### 嵌入自己的腾讯文档

1. 打开工作台 → CRM 系统 → 设置链接
2. 输入腾讯文档的分享链接
3. 在人脉运营表格中调整缩放比例

## 数据安全

所有数据存储在浏览器本地 `localStorage` 中，不会上传到任何服务器。更换浏览器或清除缓存会导致数据丢失，建议定期通过「同步到表格」功能备份到腾讯文档。
