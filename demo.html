把招聘流程变成一个可由 agent 定制的工作台

Recruiter Workbench 把 ToDo、OKR、候选人运营、目标组织地图、人才储备和触达话术放在同一个本地优先的静态网页里。默认无个人数据，适合 fork 后让 agent 快速定制。

模块速览

✓

ToDo 与 OKR

按日、周、月、半年组织任务、目标和复盘，让重复的招聘节奏沉淀下来。

▦

CRM 追踪

维护候选人进度、线索来源、备注和周期汇总，适合个人或小团队轻量运营。

◎

目标组织地图

按业务方向拆解目标组织和团队层级，支持复用组织、维护梯队和进度。

◆

人才储备

独立看板管理长期关注对象，记录主页、联系方式、优先级和跟进备注。

✎

话术模板

按聊天、打招呼、邮件场景保存触达文案，并支持变量填充与复制。

⌁

本地优先

默认只写入浏览器 localStorage，可选配置在线表格或自托管同步后端。

Agent 启动流程

$ 用户：工作台启动

agent 读取 AGENTS.md
agent 读取 skills/recruiter-workbench/SKILL.md
agent 引导填写显示名、岗位方向、目标组织
agent 按用户本地副本写入配置
agent 脱敏扫描后交付
1
读取项目规则先看 AGENTS 和 skill，知道哪些内容可以定制、哪些内容不能写进公共模板。
2
询问最小配置只问显示名、招聘范围、目标组织、表格/同步偏好这类启动所需信息。
3
生成私人工作台在用户自己的 fork 或本地副本里写入配置，不把私有数据回流到模板仓库。

默认脱敏，适合开源

这个 demo 指向的是公开模板：没有真实候选人、个人姓名、公司内链、私有文档链接或访问令牌。任何个性化内容都应发生在使用者自己的副本里。

  • 默认在线表格链接为空。
  • 默认后端同步关闭。
  • 目标组织名称使用占位符。
  • 提交前建议运行 skill 里的脱敏扫描。
