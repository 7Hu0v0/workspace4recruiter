功能有哪些

✓

ToDo 与 OKR

按日、周、月、半年组织任务、目标和复盘，适合持续招聘节奏管理。

▦

CRM 追踪

维护候选人进度、线索来源、联系方式、备注和周期汇总。

◎

目标组织地图

按业务方向拆解目标组织和团队层级，维护梯队与推进进度。

◆

人才储备看板

长期关注对象独立沉淀，记录主页、联系方式、优先级和跟进备注。

✎

话术模板

按聊天、打招呼、邮件场景保存触达文案，支持变量填充与复制。

⌁

本地优先

默认写入浏览器 localStorage，可选配置在线表格或自托管同步后端。

Agent 如何启动

$ 用户：工作台启动

agent 读取 AGENTS.md
agent 读取 skills/recruiter-workbench/SKILL.md
agent 询问显示名、岗位方向、目标组织
agent 在用户自己的副本中写入配置
agent 脱敏扫描后交付
1
先读规则明确哪些信息能写入公共模板，哪些只应该进入用户自己的副本。
2
收集最小配置显示名、招聘范围、目标组织、在线表格和同步偏好。
3
生成私人工作台复用这套开源模板，定制成个人或团队招聘操作系统。

默认脱敏，适合开源

这个 demo 不包含真实候选人、个人姓名、公司内链、私有文档链接或访问令牌。个性化内容应发生在使用者自己的 fork 或本地副本里。

  • 默认在线表格链接为空。
  • 默认后端同步关闭。
  • 目标组织名称使用占位符。
  • 提交前建议运行 skill 里的脱敏扫描。
